\begin{abstract}
This report presents the mathematical framework underlying the implemented inter-annotator agreement (IAA) analysis system for hierarchical labeling tasks. The framework encompasses three core analysis dimensions: overall agreement assessment using Krippendorff's $\alpha$, frequency-stratified agreement analysis, and hierarchical facet comparisons. The implementation uses bootstrap confidence intervals and percentage agreement measures to provide comprehensive reliability assessment for annotation tasks.
\end{abstract}

\section{Introduction and Notation}

Let $D = \{d_1, d_2, \ldots, d_n\}$ represent a set of $n$ documents to be annotated, and $A = \{a_1, a_2, \ldots, a_m\}$ represent a set of $m$ annotators. For hierarchical labeling tasks, each annotation consists of a tuple $(L_1, L_2)$ where $L_1$ represents the parent category and $L_2$ represents the child category.

\subsection{Data Structure}

The annotation data can be represented as a matrix $X \in \mathbb{R}^{m \times n}$ where:
\begin{equation}
X_{ij} = \text{label assigned by annotator } a_i \text{ to document } d_j
\end{equation}

For hierarchical analysis, we define three label spaces:
\begin{align}
\mathcal{L}_{\text{full}} &= \{(l_1, l_2) : l_1 \in \mathcal{L}_1, l_2 \in \mathcal{L}_2\} \\
\mathcal{L}_1 &= \{\text{parent categories}\} \\
\mathcal{L}_2 &= \{\text{child categories}\}
\end{align}

\section{Krippendorff's Alpha: Chance-Corrected Agreement}

\subsection{General Formulation}

Krippendorff's $\alpha$ is defined as:
\begin{equation}
\alpha = 1 - \frac{D_o}{D_e}
\end{equation}

where $D_o$ is the observed disagreement and $D_e$ is the expected disagreement under the assumption of independence.

\subsection{Implementation Algorithm}

\begin{algorithm}
\caption{Krippendorff's Alpha Calculation (as implemented)}
\begin{algorithmic}[1]
\REQUIRE Reliability data matrix $X \in \mathbb{R}^{m \times n}$
\ENSURE $\alpha$ value
\STATE Encode categorical labels using LabelEncoder
\STATE Create pivot table: annotators × documents
\STATE Convert to reliability\_data array format
\STATE \RETURN $\alpha = \text{krippendorff.alpha}(\text{reliability\_data}, \text{level\_of\_measurement='nominal'})$
\end{algorithmic}
\end{algorithm}

\section{Percentage Agreement Metrics}

\subsection{Overall Percentage Agreement}

The overall percentage agreement across all documents is defined as:
\begin{equation}
P_{\text{overall}} = \frac{1}{n} \sum_{j=1}^{n} \mathbf{1}_{\{x_{1j} = x_{2j} = \cdots = x_{mj}\}}
\end{equation}

where $\mathbf{1}_{\{\cdot\}}$ is the indicator function that equals 1 when all annotators agree on document $j$.

\subsection{Pairwise Agreement Matrix}

For annotators $a_i$ and $a_k$, the pairwise agreement is:
\begin{equation}
P_{ik} = \frac{1}{n} \sum_{j=1}^{n} \mathbf{1}_{\{x_{ij} = x_{kj}\}}
\end{equation}

The complete pairwise agreement matrix is:
\begin{equation}
\mathbf{P} = \begin{pmatrix}
100 & P_{12} & \cdots & P_{1m} \\
P_{21} & 100 & \cdots & P_{2m} \\
\vdots & \vdots & \ddots & \vdots \\
P_{m1} & P_{m2} & \cdots & 100
\end{pmatrix}
\end{equation}

where diagonal elements are 100\% and off-diagonal elements are percentage agreements.

\subsection{Document-Level Agreement Analysis}

For each document $d_j$, we calculate:
\begin{itemize}
\item Perfect agreement indicator: $\mathbf{1}_{\{\text{all annotators agree on } d_j\}}$
\item Number of unique labels assigned to $d_j$
\item Number of annotators who labeled $d_j$
\end{itemize}

\section{Frequency-Based Stratification Analysis}

\subsection{Label Frequency Distribution}

Let $f_\ell$ denote the frequency of label $\ell$ across all annotations:
\begin{equation}
f_\ell = \sum_{i=1}^{m} \sum_{j=1}^{n} \mathbf{1}_{\{x_{ij} = \ell\}}
\end{equation}

\subsection{Frequency-Based Stratification}

Using quantiles $Q_{33}$ and $Q_{67}$ (33rd and 67th percentiles), we partition labels into three frequency strata:
\begin{align}
\mathcal{S}_{\text{rare}} &= \{\ell : f_\ell \leq Q_{33}\} \\
\mathcal{S}_{\text{moderate}} &= \{\ell : Q_{33} < f_\ell \leq Q_{67}\} \\
\mathcal{S}_{\text{common}} &= \{\ell : f_\ell > Q_{67}\}
\end{align}

\subsection{Stratified Agreement Analysis}

For each stratum $\mathcal{S}_s$, we create a subset of data containing only annotations with labels in that stratum:
\begin{equation}
X^{(s)} = \{x_{ij} : x_{ij} \in \mathcal{S}_s\}
\end{equation}

We then calculate stratum-specific agreement:
\begin{equation}
\alpha^{(s)} = \text{KrippendorffAlpha}(X^{(s)})
\end{equation}

If Krippendorff's $\alpha$ fails due to insufficient variation, we use simple agreement rate as fallback:
\begin{equation}
\text{SimpleAgreement}^{(s)} = \frac{\text{Number of documents with perfect agreement in } \mathcal{S}_s}{\text{Total documents in } \mathcal{S}_s}
\end{equation}

\section{Hierarchical Analysis}

\subsection{Three-Level Decomposition}

For hierarchical labels $(L_1, L_2)$, we analyze agreement at three levels:

\subsubsection{Parent Level Analysis (L1)}
Extract parent labels: $X^{(1)}_{ij} = \pi_1(X_{ij})$ where $\pi_1$ projects to the first component.

\subsubsection{Child Level Analysis (L2)}
Extract child labels: $X^{(2)}_{ij} = \pi_2(X_{ij})$ where $\pi_2$ projects to the second component.

\subsubsection{Full Hierarchical Analysis}
Use complete label tuples: $X^{(\text{full})}_{ij} = X_{ij} = (L_1, L_2)$ concatenated as strings.

\subsection{Conditional Agreement Analysis}

For each parent category $\ell_1 \in \mathcal{L}_1$, we analyze agreement on child categories within that parent:
\begin{equation}
\text{ConditionalAnalysis}(\ell_1) = \text{Agreement analysis on } \{x_{ij} : \pi_1(x_{ij}) = \ell_1\}
\end{equation}

\subsection{Parent-Child Combination Analysis}

We calculate agreement rates for specific $(L_1, L_2)$ combinations by computing perfect agreement rates for documents where at least one annotator used that specific combination.

\section{Bootstrap Confidence Intervals}

For Krippendorff's $\alpha$, we construct confidence intervals using bootstrap resampling at the document level:

\begin{algorithm}
\caption{Bootstrap Confidence Interval (as implemented)}
\begin{algorithmic}[1]
\REQUIRE Data matrix $X$, confidence level $(1-\gamma)$, bootstrap samples $B$
\ENSURE Confidence interval $[L, U]$
\FOR{$b = 1$ to $B$}
    \STATE Sample documents with replacement: $D^{(b)} \sim \text{Uniform}(D)$
    \STATE Filter annotations for sampled documents
    \STATE IF $|D^{(b)}| > 10$ THEN
        \STATE Compute $\alpha^{(b)} = \text{KrippendorffAlpha}(X^{(b)})$
        \STATE IF $\alpha^{(b)}$ is not NaN THEN add to bootstrap collection
    \STATE ENDIF
\ENDFOR
\STATE $L = \text{percentile}(\gamma/2 \times 100)$
\STATE $U = \text{percentile}((1-\gamma/2) \times 100)$
\STATE \RETURN $[L, U]$
\end{algorithmic}
\end{algorithm}

\section{Implementation Considerations}

\subsection{Computational Complexity}

The implemented algorithms have the following computational complexities:
\begin{itemize}
\item Krippendorff's $\alpha$: $O(mn \cdot |\mathcal{L}|^2)$ where $|\mathcal{L}|$ is the number of unique labels
\item Percentage agreement: $O(mn)$
\item Pairwise matrix: $O(m^2 n)$
\item Bootstrap intervals: $O(B \cdot \text{base computation})$ where $B$ is the number of bootstrap samples
\item Hierarchical analysis: $O(3 \cdot mn \cdot |\mathcal{L}|^2)$ for three label types
\item Frequency stratification: $O(mn + |\mathcal{L}| \log |\mathcal{L}|)$ for sorting
\end{itemize}

\subsection{Numerical Stability and Error Handling}

The implementation handles several edge cases:

\begin{itemize}
\item \textbf{Insufficient data}: Minimum sample size checks ($n > 10$ documents)
\item \textbf{Krippendorff failure}: Fallback to simple agreement rate calculation
\item \textbf{Missing annotations}: Automatic exclusion from pairwise comparisons using pandas dropna()
\item \textbf{Bootstrap failures}: Skip invalid bootstrap samples and report valid sample count
\item \textbf{Single-label strata}: Return perfect agreement (1.0) when all labels in stratum are identical
\item \textbf{Empty intersections}: Return NaN for undefined agreement calculations
\end{itemize}

\subsection{Data Preparation}

\begin{enumerate}
\item \textbf{Label encoding}: Categorical labels converted to numeric using sklearn LabelEncoder
\item \textbf{Pivot transformation}: Data reshaped to annotator × document matrix format
\item \textbf{Missing value handling}: NaN values preserved in reliability data matrix
\item \textbf{Type conversion}: Arrays converted to float64 for numerical stability
\end{enumerate}

\section{Practical Interpretation Guidelines}

\subsection{Krippendorff's Alpha Interpretation}

\begin{itemize}
\item $\alpha \geq 0.8$: Excellent reliability
\item $0.67 \leq \alpha < 0.8$: Good reliability (acceptable for tentative conclusions)
\item $0.4 \leq \alpha < 0.67$: Fair reliability (questionable)
\item $\alpha < 0.4$: Poor reliability (unacceptable)
\end{itemize}

\subsection{Confidence Interval Interpretation}

Confidence intervals that:
\begin{itemize}
\item Do not include 0.67: Strong evidence for reliability level
\item Cross reliability thresholds: Uncertain reliability classification
\item Are very wide ($> 0.2$): Insufficient data for reliable estimation
\end{itemize}

\subsection{Hierarchical Analysis Insights}

\begin{itemize}
\item $\alpha^{(1)} > \alpha^{(2)} > \alpha^{(\text{full})}$: Expected pattern (easier to agree on broad categories)
\item $\alpha^{(\text{full})} \approx \alpha^{(1)}$: Child categories may be redundant
\item $\alpha^{(2)} > \alpha^{(1)}$: Unexpected pattern requiring investigation
\end{itemize}

\section{Dashboard Integration}

The mathematical framework is implemented across three main dashboard components:

\begin{enumerate}
\item \textbf{Overall Agreement Analysis}: Krippendorff's $\alpha$ with bootstrap CI, pairwise matrices, document-level statistics
\item \textbf{Frequency Analysis}: Stratified analysis by label frequency with distribution plots
\item \textbf{Hierarchical Analysis}: Three-level decomposition with conditional and combination analysis
\end{enumerate}

Each component provides both numerical results and interactive visualizations for practical decision-making.

\section{Conclusions}

This framework provides a comprehensive foundation for IAA analysis that balances theoretical rigor with practical implementation:

\begin{enumerate}
\item \textbf{Chance-corrected reliability}: Krippendorff's $\alpha$ accounts for expected agreement by chance
\item \textbf{Intuitive interpretation}: Percentage agreements complement $\alpha$ with easily interpretable metrics
\item \textbf{Robust confidence estimation}: Bootstrap methods provide reliable confidence intervals
\item \textbf{Hierarchical insights}: Multi-level decomposition reveals structure-specific agreement patterns
\item \textbf{Frequency effects}: Stratification analysis identifies how label rarity affects agreement
\item \textbf{Error resilience}: Comprehensive error handling ensures stable operation
\end{enumerate}

The framework supports reliable assessment of annotation quality for complex hierarchical labeling tasks while maintaining computational efficiency and numerical stability.
